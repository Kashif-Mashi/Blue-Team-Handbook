# Lab 12 – Bash Scripting

## Scenario

The Security Operations Center (SOC) performs the same administrative tasks every day, including collecting logs, checking disk usage, monitoring running services, and creating backups. Performing these tasks manually is time-consuming and increases the chance of human error.

As a Blue Team Analyst, your responsibility is to automate routine tasks using Bash scripting to improve efficiency and consistency.

---

# Mission

Learn how to create and execute Bash scripts to automate common Linux administration and security tasks.

---

# Story

Your SOC manager notices that analysts spend hours every day performing repetitive system checks.

He says:

> *"Time is one of our most valuable resources. If a task is performed every day, it should be automated. Build scripts that work for you, so you can focus on finding threats instead of repeating commands."*

Your mission is to develop simple Bash scripts that automate everyday administrative and security operations.

---

# Learning Objectives

After completing this lab, you will be able to:

* Understand the purpose of Bash scripting.
* Create executable Bash scripts.
* Use variables in scripts.
* Accept user input.
* Work with conditional statements.
* Use loops for repetitive tasks.
* Automate common Linux administration tasks.

# Your Tasks

Complete the following tasks using Bash scripting.

### Task 1 – Create Your First Script

Create a Bash script.

Verify that:

* The script has the correct shebang.
* It can be executed successfully.

---

### Task 2 – Display System Information

Modify your script to display useful system information such as:

* Current user
* Hostname
* Current date and time
* Current working directory

---

### Task 3 – Accept User Input

Update your script so it requests information from the user.

Display the entered information in a readable format.

---

### Task 4 – Work with Variables

Store values in variables.

Use those variables throughout your script.

---

### Task 5 – Make Decisions

Use conditional logic to perform different actions depending on user input or system conditions.

Verify that each condition behaves as expected.

---

### Task 6 – Automate Repetitive Tasks

Use a loop to repeat an action automatically.

Document what your loop accomplishes.

---

### Task 7 – Create a Basic Security Script

Develop a simple script that collects useful security information, such as:

* Logged-in users
* Disk usage
* Running processes
* System uptime
* Network information

Save the output as a report.

---

### Task 8 – Test and Document Your Script

Execute your script several times.

Verify that:

* It produces the expected output.
* Errors are handled appropriately.
* The generated report contains accurate information.
