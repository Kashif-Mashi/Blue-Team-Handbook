## Note

The detailed installation and configuration guide for **Kali Linux** is not included in this lab to avoid duplication within the handbook.

If you have not yet installed or configured Kali Linux, please visit the **Security Operations → Kali Linux Guide** section, where you will find comprehensive, step-by-step instructions covering:

* Downloading the official Kali Linux ISO
* Installing Oracle VirtualBox
* Creating a Kali Linux virtual machine
* Configuring CPU, RAM, and storage
* Setting up networking (NAT/Host-Only)
* Installing Kali Linux
* Updating the operating system
* Installing VirtualBox Guest Additions
* Creating a virtual machine snapshot
* Troubleshooting common installation issues

Once you have successfully completed the Kali Linux setup, return to this lab and complete the remaining objectives.

> **Prerequisite:** A fully functional Kali Linux virtual machine is required before proceeding with the Linux Labs. Ensure your system is updated and operational before moving to the next exercise.
