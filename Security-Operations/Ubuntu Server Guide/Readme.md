# Ubuntu Server Guide

A practical, beginner-friendly guide to installing, configuring, and managing **Ubuntu Server 22.04.5 LTS** for cybersecurity home labs and enterprise environments.

This guide is part of the **Blue Team Handbook** project and provides the Ubuntu Server knowledge required before deploying tools such as **Wazuh**, **Docker**, and other security solutions.

---

## 📖 About

This guide walks through the complete Ubuntu Server deployment process, from downloading the ISO to configuring networking, enabling SSH, and managing software packages.

The content is written for:

- Cybersecurity Students
- SOC Analyst Aspirants
- Linux Beginners
- System Administrators
- Home Lab Enthusiasts
