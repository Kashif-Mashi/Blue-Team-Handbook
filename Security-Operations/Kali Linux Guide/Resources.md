# Notes

- Always download Kali Linux from the official website.
- Keep your system updated using `sudo apt update` and `sudo apt full-upgrade`.
- Practice only in authorized environments such as your own home lab or CTF platforms.
- Follow responsible disclosure and ethical hacking principles.
- Refer to official documentation whenever possible before using third-party resources.

**Disclaimer:** The resources listed in this document are provided for educational purposes. Always use security tools responsibly and only on systems you own or have explicit permission to test.
