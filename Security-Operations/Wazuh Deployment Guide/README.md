# Wazuh Deployment Guide

A comprehensive, beginner-friendly guide to installing, configuring, and deploying **Wazuh SIEM** for cybersecurity learning and Blue Team home labs.

This guide is part of the **Blue Team Handbook**, an open-source project designed to help students and aspiring cybersecurity professionals build practical Blue Team skills through structured documentation and hands-on labs.

---

## About

Wazuh is an open-source security platform that provides Security Information and Event Management (SIEM), Extended Detection and Response (XDR), File Integrity Monitoring (FIM), Vulnerability Detection, Log Analysis, and Incident Response capabilities.

This guide takes you through the complete deployment process—from preparing the server to connecting agents and monitoring security events in a home lab environment.

## Learning Outcomes

After completing this guide, you will be able to:

- Understand Wazuh architecture
- Deploy a Wazuh Server
- Access the Wazuh Dashboard
- Configure the Wazuh Manager
- Deploy Linux and Windows agents
- Monitor logs and alerts
- Understand Wazuh security features
- Troubleshoot common deployment issues

## Prerequisites

Before starting this guide, you should have:

- Ubuntu Server installed
- Basic Linux knowledge
- Oracle VirtualBox
- Internet connection
- Static IP configuration
