# Chapter 10 – Windows Event Viewer & Logging

## Overview

Windows keeps a record of important system activities in the form of **logs**. These logs help administrators and security analysts understand what is happening on a computer, troubleshoot problems, and investigate security incidents.

The **Event Viewer** is a built-in Windows tool that allows you to view and analyze these logs.

Learning how to use Event Viewer is an important skill because logs often provide the first clues during a cybersecurity investigation.

---

## Learning Objectives

After completing this chapter, you will be able to:

- Understand what Event Viewer is
- Learn about different Windows log categories
- Understand Security logs
- Recognize the purpose of Event IDs

- Understand how Blue Teams use Windows logs

---

# What is Event Viewer?

**Event Viewer** is a built-in Windows application that displays logs generated by Windows, applications, and system components.

Whenever something important happens, such as a user logging in, a program crashing, or Windows starting, an event is recorded in the logs.

These logs help identify problems, monitor system activity, and investigate suspicious behavior.

---

## Opening Event Viewer

There are several ways to open Event Viewer.

### Method 1

- Press **Windows + X**
- Select **Event Viewer**

### Method 2

- Press **Windows + R**
- Type:

```text
eventvwr.msc
```

- Press **Enter**

### Method 3

- Open the **Start Menu**
- Search for **Event Viewer**

# Windows Logs

The **Windows Logs** section contains the most important logs used for troubleshooting and security investigations.

The main log categories are:

| Log | Purpose |
|------|---------|
| Application | Events generated by applications |
| Security | Login attempts and security-related events |
| System | Windows system events and hardware information |
| Setup | Windows installation and update events |
| Forwarded Events | Events collected from other computers |

---

# Security Logs

The **Security** log records security-related activities on the computer.

Examples include:

- Successful logins
- Failed login attempts
- User account changes
- Password changes
- Account lockouts

Security logs are one of the most valuable sources of information during a security investigation.

---

# Event IDs

Every event recorded in Windows has a unique **Event ID**.

The Event ID helps identify the type of activity that occurred.

Some common Security Event IDs include:

| Event ID | Description |
|----------|-------------|
| 4624 | Successful user logon |
| 4625 | Failed logon attempt |
| 4634 | User logoff |
| 4720 | User account created |
| 4726 | User account deleted |

> **Note**
>
> You do not need to memorize Event IDs. With experience, you will naturally become familiar with the most common ones.

---

# Viewing Event Details

To view an event:

1. Open **Event Viewer**.
2. Expand **Windows Logs**.
3. Select a log category, such as **Security**.
4. Click an event.
5. Review its details in the lower pane.

Important information includes:

- Event ID
- Date and time
- Event level
- Source
- Description

---

# Filtering Events

As the number of logs increases, finding specific events becomes more difficult.

Event Viewer allows you to filter logs based on:

- Event ID
- Date
- Event Level
- Keywords

Filtering helps you quickly locate relevant events during troubleshooting or investigations.

---

# Basic Log Analysis

When reviewing logs, ask yourself questions such as:

- When did the event occur?
- Which user was involved?
- Was the action successful or failed?
- Is this activity expected?
- Does anything look unusual?

Looking for patterns instead of individual events makes investigations easier.

# Useful Commands

You can also access Windows event logs using PowerShell.

### Display Event Logs

```powershell
Get-EventLog -LogName System
```

### Display Security Logs

```powershell
Get-EventLog -LogName Security
```

> **Note**
>
> Administrator privileges may be required to access some Security logs.

---

# Blue Team Perspective

Windows logs are one of the most important sources of information for Blue Team professionals.

Security analysts use Event Viewer to:

- Investigate failed login attempts
- Review successful logins
- Identify user account changes
- Troubleshoot system errors
- Collect evidence during incident response

Many cyber attacks leave traces in Windows logs, making Event Viewer an essential investigation tool.

# Key Points

- Event Viewer is used to view Windows logs.
- Windows records important system and security events.

- Every event has a unique Event ID.
