# Lab 03 – Shell & Terminal Basics

## Scenario

During a security investigation, graphical tools are not always available. Many Linux servers run without a graphical interface, requiring security analysts to perform investigations entirely from the command line.

As a Blue Team Analyst, you must become comfortable working in the Linux terminal to efficiently manage systems and respond to incidents.

---

# Mission

Master the Linux terminal by learning how to interact with the Bash shell, execute commands, access documentation, and maintain an efficient command-line workflow.

---

# Story

You have successfully explored the Linux file system. Your team leader now disables the graphical interface and says:

> *"Real analysts don't rely on windows and buttons. The terminal is where investigations begin. Learn to communicate with the system, and it will reveal everything you need."*

Your mission is to become comfortable using the Linux terminal as your primary workspace.

---

# Learning Objectives

After completing this lab, you will be able to:

* Understand the difference between the terminal and the shell.
* Identify your current shell.
* Execute Linux commands.
* Use command history effectively.
* Access built-in documentation.
* Clear and organize the terminal.
* Navigate command-line help resources.

---

# Prerequisites

Before starting this lab, ensure you have:

* Completed **Lab 01 – Build Your Cyber Lab**
* Completed **Lab 02 – Linux File System Exploration**
* A working Kali Linux virtual machine

---

# Clues

> **"The terminal only obeys precise instructions."**

> **"If you don't know a command, ask Linux—it already knows the answer."**

> **"Every command leaves a trail. Learn to use your history wisely."**

---

# Your Tasks

Complete the following tasks using only the Linux terminal.

### Task 1 – Open the Terminal

Launch the terminal and identify the default shell being used.

---

### Task 2 – Execute Basic Commands

Run several basic commands to understand how the shell responds.

Observe:

* Command execution
* Output
* Error messages

---

### Task 3 – View Command History

Display previously executed commands.

Navigate through command history using your keyboard.

---

### Task 4 – Learn to Use Help

Find documentation for common Linux commands using built-in help tools.

Explore:

* Manual pages
* Command help options
* Information pages

---

### Task 5 – Experiment with Auto-Completion

Use keyboard shortcuts to:

* Auto-complete commands
* Auto-complete directory names
* Reduce typing errors

---

### Task 6 – Clear and Organize Your Terminal

Practice keeping your terminal clean while continuing your work.

---

### Task 7 – Create a Personal Command Reference

Create a small note containing:

* Commands you learned
* Their purpose
* When you would use them during an investigation

---

# Success Criteria

You have successfully completed this lab if you can:

* Open and use the terminal confidently.
* Explain what the Bash shell is.
* Execute Linux commands successfully.
* Access command documentation.
* Use command history.
* Auto-complete commands and file names.
* Maintain an organized terminal workspace.

# Blue Team Insight

SOC analysts spend a significant portion of their day working in terminals.

Command-line proficiency allows you to:

* Investigate compromised systems
* Search logs efficiently
* Manage remote Linux servers
* Automate repetitive tasks
* Respond quickly during security incidents

A strong understanding of the terminal is one of the most valuable skills for any cybersecurity professional.
