# 📖 About This Guide

This guide walks you through the complete process of building a **Wazuh Home Lab** from scratch. Every chapter is designed for beginners and explains not only **what to do**, but also **why each step is important**.

Throughout this guide, you will learn how to:

* Install Wazuh on Ubuntu Server
* Configure the Wazuh Dashboard
* Understand the Wazuh architecture
* Deploy Windows and Linux agents
* Verify communication between endpoints and the manager
* Troubleshoot common installation and networking issues
* Build a solid foundation for Security Operations (SOC)

# 🎯 Learning Outcomes

After completing this guide, you will be able to:

* Deploy a complete Wazuh SIEM environment
* Install and configure Ubuntu Server for Wazuh
* Connect Windows and Linux endpoints
* Monitor endpoint activity in the Wazuh Dashboard
* Understand the role of the Wazuh Manager, Indexer, and Dashboard
* Troubleshoot common installation and agent connectivity issues
* Prepare a lab environment for SOC and Blue Team exercises
