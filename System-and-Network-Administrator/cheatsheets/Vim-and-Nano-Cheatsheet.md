# Vim and Nano Cheatsheet

## Vim
| Action | Key/command |
|---|---|
| Open | `vim filename` |
| Insert | `i` |
| Normal mode | `Esc` |
| Save | `:w` |
| Quit | `:q` |
| Save and quit | `:wq` |
| Quit without saving | `:q!` |
| Delete line | `dd` |
| Copy line | `yy` |
| Paste | `p` |
| Undo | `u` |
| Search | `/word` then Enter |
| Next match | `n` |
| First/last line | `gg` / `G` |

## Nano
| Action | Shortcut |
|---|---|
| Open | `nano filename` |
| Save | `Ctrl+O`, then Enter |
| Exit | `Ctrl+X` |
| Search | `Ctrl+W` |
| Cut line | `Ctrl+K` |
| Paste cut text | `Ctrl+U` |

Nano versions can vary; `^` in its hints usually means Ctrl. Review configuration files before editing.
