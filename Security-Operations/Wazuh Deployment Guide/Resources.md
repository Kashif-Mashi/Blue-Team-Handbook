## Notes

- Download Wazuh only from the official website.
- Keep Ubuntu Server updated before installing Wazuh.
- Test deployments in a home lab before production use.
- Follow the official Wazuh documentation for version-specific changes.
- Document any configuration changes you make during deployment.
