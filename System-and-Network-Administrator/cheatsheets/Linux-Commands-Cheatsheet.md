# Linux Commands Cheatsheet

| Command | Purpose |
|---|---|
| `pwd` | Show current directory |
| `ls -l` | Detailed directory listing |
| `ls -a` | Include hidden names |
| `cd /path` | Change directory |
| `whoami` | Show effective user |
| `id` | Show user/group IDs |
| `hostname` | Show host name |
| `uname -a` | Kernel/system information |
| `cat file` | Print file contents |
| `head file` / `tail file` | Beginning/end of file |
| `grep 'text' file` | Search matching lines |
| `wc -l file` / `wc -w file` | Count lines/words |
| `df -h` | Filesystem space |
| `ps` / `top` | Process information |
| `man command` | Read manual |

Options vary by system. Inspect targets before changing anything.
