# Support

Thank you for your interest in the **Blue Team Handbook**.

This document explains how to get help, ask questions, report problems, and contribute to improving the project.

---

# Before Asking for Help

Before opening an issue, please check the following:

- Read the **README.md**
- Check the **FAQ.md**
- Review the guide carefully
- Search existing GitHub Issues
- Verify that you are using the latest version of the documentation

Many common questions have already been answered.

---

# Getting Help

If you need assistance with one of the guides:

1. Verify each step carefully.
2. Read the troubleshooting section in the guide.
3. Check the official documentation of the related software.
4. If the problem persists, open a GitHub Issue.

When asking for help, please include:

- Guide name
- Chapter number
- Operating System
- Software version
- Error message
- Screenshots (if applicable)
- Steps you have already tried

Providing detailed information helps resolve issues more quickly.

---

# Reporting Documentation Issues

If you notice:

- Spelling mistakes
- Broken links
- Incorrect commands
- Formatting issues
- Outdated screenshots
- Missing explanations

Please open a GitHub Issue.

Documentation improvements are always appreciated.

---

# Reporting Technical Issues

Examples include:

- Installation failures
- Network configuration problems
- Wazuh deployment issues
- VirtualBox configuration errors
- Windows configuration issues
- Ubuntu Server problems

Please include:

- Your virtualization platform
- Operating system version
- Error logs
- Screenshots
- Configuration details
