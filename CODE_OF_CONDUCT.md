# Code of Conduct

## Our Pledge

We, as contributors and maintainers of the **Blue Team Handbook**, pledge to make participation in our community a respectful, welcoming, and harassment-free experience for everyone.

Regardless of age, body size, disability, ethnicity, gender identity or expression, level of experience, education, nationality, personal appearance, race, religion, or sexual identity and orientation, we are committed to fostering an inclusive environment where people can learn and contribute.

The goal of this project is to provide free, high-quality educational resources for the cybersecurity community.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and welcoming.
- Using constructive and professional language.
- Accepting constructive feedback gracefully.
- Helping beginners learn.
- Sharing knowledge responsibly.
- Respecting different opinions and experiences.
- Focusing discussions on improving the project.

Examples of unacceptable behavior include:

- Harassment or discrimination of any kind.
- Personal attacks or insults.
- Trolling or intentionally disruptive behavior.
- Publishing another person's private information without permission.
- Posting malicious content or unsafe material.
- Encouraging illegal or unethical activities.
- Spam or self-promotion unrelated to the project.

---

# Educational Responsibility

The Blue Team Handbook exists to promote ethical cybersecurity education.

Contributors should:

- Encourage responsible learning.
- Promote defensive security practices.
- Respect applicable laws and regulations.
- Avoid publishing content intended to facilitate unauthorized access or malicious activity.

All practical exercises should be designed for authorized home labs, educational environments, or systems where permission has been granted.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Repository comments
- Any official communication related to this project

It also applies when representing the Blue Team Handbook in public spaces.

---

# Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please report it by opening a GitHub Issue (if appropriate) or contacting the repository maintainer.

Reports should include:

- A description of the incident.
- Relevant links or screenshots (if available).
- Any additional context that may help.

All reports will be reviewed respectfully and confidentially where possible.

---

# Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Maintainers may:

- Request changes to inappropriate content.
- Remove offensive comments.
- Close discussions that become unproductive.
- Restrict participation when necessary.
- Remove contributions that violate this Code of Conduct.

Actions will be taken fairly and consistently.

---

# Enforcement Guidelines

Maintainers may respond to unacceptable behavior with actions including:

### Correction

A private or public reminder explaining why the behavior was inappropriate.

---

### Warning

A formal warning requesting that the behavior stop.

---

### Temporary Restriction

Temporary suspension from discussions or contributions.

---

### Permanent Ban

In cases of repeated or severe misconduct, contributors may be permanently restricted from participating in the project.
